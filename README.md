## 🎮 Installation

1. Download both behavior and resource packs
2. Move to Bedrock add-ons folder:
   - **Windows**: `%appdata%\.minecraft\development_behavior_packs\` and `development_resource_packs\`
3. Enable in world settings
4. Done!

## 💎 Features

✅ All items fully enchanted at Level 30 with treasure enchants
✅ Each trade provides 27 stacks (maximum shulker box capacity)
✅ Ready to use - no further configuration needed
✅ Works in Survival mode to unlock endgame progression

## 📋 Technical Details

- Format Version: 1.20.0+

Spawn the villager and interact to see all 22 trades. Trade emeralds for powerful shulker boxes!
